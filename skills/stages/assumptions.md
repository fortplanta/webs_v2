Make the bets explicit instead of smuggling them in. For each option in the Options Table extract the core assumptions ("for this to work, X must be true"). Cross-check with the Pattern Table: where the opposite pattern has shown up before, highlight it as a risk.

For each assumption or risk: a description; the linked option or options; the impact if it's wrong; current confidence (low, medium, high); and a concrete test (metric, threshold, timeframe, and the smallest version of the option that could test it).
