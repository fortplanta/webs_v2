Using the Situation Card, build a compact System Snapshot: how does this machine actually run in practice?
- Who wants what: goals, incentives and fears for each actor.
- Flows of information, decisions, approvals, money and attention.
- Feedback loops and cycles (for example: bad brief, then rework, then a tighter deadline, then a worse brief).
- Hard constraints (legal, time, physical) versus soft ones (habits, norms, arbitrary rules).

Then say what the system appears to be optimising for in practice, which may contradict the stated goal. On thin input, say what you're inferring versus what's actually stated.
