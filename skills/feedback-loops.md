name: Feedback loops
mode: control
hint: Loops that stack wins and squash screwups
---
Build feedback loops into the selected process or system that make the wins stack up and the screwups get squashed.

Show how each cycle nudges things in the right direction, not just endlessly circles the drain: for each loop give the signal, the response, how often, and what it reinforces or corrects. If you spot an existing or proposed loop that will backfire or turn toxic, flag it and say how.

Finish with the one loop to build first and the guardrail that stops it being gamed.
