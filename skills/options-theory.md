name: Options
mode: control
hint: Paths, levers, risks, hedges and a recommendation
---
Given the selected content, identify the core decision or bet being made.

1. Zoom out: restate the situation at a higher level of abstraction. What game is really being played?
2. Map options: list the main strategic options or paths available, including non-obvious or hybrid ones.
3. Levers: for each option, the key levers that can be pulled (resources, timing, framing, relationships, pricing, positioning and so on) to increase the number of ways it can succeed.
4. Risks: the main risks, failure modes and hidden assumptions for each option.
5. Hedges and flexibility: specific ways to keep flexibility (reversible steps, small experiments, diversification, staged commitments) so the person isn't locked into disaster if conditions change.
6. Recommendation: a default path plus one or two plan B/C variants, and when to switch between them (clear triggers or signals).
