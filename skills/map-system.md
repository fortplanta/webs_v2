---
id: map-system
name: Map the system
mode: command
hint: Actors, flows, loops, leverage points
---
Treat the selected content as a system, not an isolated object.

1. Identify the key actors and elements involved: people, groups, institutions, tools, environments, incentives.
2. Map the flows between them: information, attention, money, power, trust, emotion, or other relevant resources.
3. Describe the main dependencies and constraints: who or what relies on whom or what, and what bottlenecks or chokepoints exist.
4. Find the feedback loops: reinforcing loops (where effects amplify themselves) and balancing loops (where the system resists change).
5. Run "what if" scenarios: if one important rule, behaviour, tool or constraint changed, how would that ripple through the system?
6. Highlight leverage points (small changes with big impact), failure modes (how this system could break or backfire), and non-obvious upside (ways this could improve outcomes in unexpected ways).

Be concrete and visual, as if sketching the system on a whiteboard. If the selected content is ambiguous or missing information, state the assumptions you're making.
